# Methodology

## Scope
Primary window: 2022–2026.

Current emphasis:
- robotics
- autonomy
- control
- mechanical engineering
- mechatronics
- dynamics
- mechanics
- design / optimization
- selected adjacent areas

This is not yet an institute-wide census of every department.

## Publication counting

### Full journals
Count as **1.0** in the journal-equivalent score.

### RA-L / short letters
Count as **0.5** in the journal-equivalent score.

### Conferences
Tracked separately.

## Time-of-hiring reconstruction
The aim is to estimate the profile that existed approximately when the person joined the institution, not merely report current metrics.

Source priority:
1. official institute/faculty page
2. personal CV/publication page
3. dated seminar biography
4. Google Scholar / OpenAlex / Semantic Scholar / ORCID / Crossref
5. other public bibliographic sources

## Citations
Historical citation values are labeled as:
- dated / near-date
- reconstructed estimate/range
- not publicly recoverable

Current citations must not silently replace historical values.

## Institute statistics
- numeric ranges use their midpoint
- open-ended values such as `40+` use the lower bound conservatively
- sample SD is used
- unrecoverable historical citation values are excluded from citation mean/SD
- N used is displayed per metric

## Postdoc duration
Counts formal postdoctoral or research-associate training after the PhD and before appointment.

Industry R&D is not counted as postdoc time.

## Limitations
The dataset does not model:
- department-specific strategic hiring
- reference letters
- interview/seminar performance
- research independence
- teaching
- funding potential
- timing
- internal institutional priorities
